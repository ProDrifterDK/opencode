Key design decisions:
- Service yields Bus.Service at layer build time (not in Effect.fn methods)
- Mailbox.Service yielded at runtime via Effect.fn (like lead-coordinator pattern)
- Urgent messages (priority === "urgent") always bypass summarization
- Default threshold: 10 messages, configurable via SummarizerConfig
- defaultSummarizeFn: synchronous text summary from MessageBatch[]
- Custom summarizeFn injection point for future LLM integration
- BusEvent.Summarized published with metrics (originalCount, summaryCount, preservedUrgent)
- SummarizerError tagged error for typed error handling
